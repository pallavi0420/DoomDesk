Data Collection

  • Account information (name, email, phone, hostel details)
  • Complaint details and photos
  • Feedback and ratings
  • Usage analytics (optional)

Data Usage

Data is stored in Firebase Realtime Database and Firebase Storage. It is used solely to provide the hostel management services.

Data Sharing

No data is shared with third parties except the optional Groq AI service for the DormDesk AI chatbot. The Groq API receives only the user query and no personally identifiable information.

Security

All network communication uses HTTPS. Authentication is handled by Firebase Auth.

User Rights

Users can request deletion or correction of their data via the app or by contacting the hostel administration.

Contact

For privacy inquiries, contact: support@dormdesk.example.com
